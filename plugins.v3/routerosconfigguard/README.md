# RouterOS 配置备份与漂移检测（RouterOSConfigGuard）

定时备份 MikroTik RouterOS（v7 REST API）的关键配置分区为快照，与基线做**指纹对比**，
检测配置的**新增 / 删除**并高亮敏感分区（防火墙、NAT、路由、DNS、用户、脚本等）；
同时巡检 MoviePilot 已连接的下载器与媒体服务器在线状态。漂移或异常时通过 MP 通知推送。

## 为什么需要它

- 家庭/工作室的 RouterOS 配置改来改去（优选 IP、端口转发、限速队列、防火墙），
  一旦出问题很难回答"到底改了什么、什么时候改的"。
- 本插件把配置读成标准化快照（剔除 `.id` 与每分钟都在变的统计字段），
  只比对"真实配置"，避免假漂移；敏感分区变更即时告警。

## 配置要点

### 1. RouterOS 连接
- 地址填 `192.168.1.1` 或 `https://ros.local`；端口默认 443，可切 HTTP。
- 用户名需具备 **read / api / rest-api** 权限。自签证书建议保持"使用 HTTPS"开启
  （插件对自签证书不做强校验，与 CFRouterOS 行为一致）。
- 保存前可用详情页「测试连接」验证。

### 2. 备份分区（下拉多选）
默认勾选 12 个常用分区；另有 DHCP 租约、Mangle、服务端口、系统用户/计划任务/脚本等可加选。
**敏感分区**（路由、DNS、防火墙、地址列表、服务、用户、脚本、计划任务）一旦漂移会高亮告警。

### 3. 关联服务巡检（本次重点：直接勾选 MP 已连接实例）
- **下载器**下拉框：自动列出 MoviePilot 中已启用且类型为 qBittorrent / Transmission 的实例。
- **媒体服务器**下拉框：自动列出 MP 中已配置的 Emby / Plex / Jellyfin 实例。
- 勾选后，每轮备份会附带巡检这些实例是否在线（`is_inactive()`），离线时告警。
- **预留手动补充**：若需监控 MP 之外或额外的多套实例，在「手动补充」框填名称（逗号分隔），
  会与下拉勾选合并去重。手动补充项若不在 MP 实例中，巡检会标注"MP 外手动项属正常"，不影响备份主流程。

### 4. 基线与周期
- **首次自动设基线**：无基线时把首份快照设为对比基准（推荐保留开启）。
- `cron` 默认 `0 3 * * *`（每天 03:00）；`*/5 * * * *` 表示每 5 分钟。
- 快照以 JSON 写入插件数据目录 `snapshots/`，按「保留份数」自动轮转删除最旧的。
- 「最近设为基线」可随时把最新快照设为新基准（例如确认一次大改是合理的之后）。

## 漂移是如何判定的

1. 每个分区的每一行配置，剔除易变字段（`.id`、`bytes`、`uptime`、`rate` 等）后做稳定 SHA256 指纹。
2. 快照保存为 `{分区: [指纹列表 + 规范化行]}`。
3. 当前快照与基线按指纹**多重集**对比：同一指纹出现次数一致即视为未变；
   多出来的记「新增」、缺少的记「删除」。修改某个字段必然表现为「一行删除 + 一行新增」，语义更强。
4. 通知/详情页输出按分区分组的差异明细，敏感分区带 ⚠ 标记。

> 例：把 `a.local` 的解析从 `1.1.1.1` 改成 `8.8.8.8`，会报告 DNS 静态记录 `+1 / -1`。

## 使用流程

1. 安装并启用插件，填 RouterOS 地址/账号，选备份分区、勾选关联服务。
2. 点配置页「立即执行一次」（或详情页「立即备份并检测」）生成首份快照并自动设为基线。
3. 之后由 cron 定时检测；发生漂移或关联服务离线时收到 MP 通知。
4. 若某次变更是预期的，点「最近设为基线」以新快照为基准，避免持续告警。

## 详情页 / API / 远程命令

- **详情页**：插件状态、基线时间、快照份数、最近漂移明细、关联服务在线状态、快照清单、INFO 级实时日志，
  以及「立即备份并检测 / 测试连接 / 最近设为基线 / 清空快照 / 停止」按钮。
- **API**：`/run` `/test` `/baseline` `/snapshots` `/status` `/clear` `/stop`（前缀 `/plugin/RouterOSConfigGuard`）。
- **远程命令**：`/rosguard_status` `/rosguard_run` `/rosguard_baseline` `/rosguard_clear`。

## 安全说明

- 插件对 RouterOS **只读**（全部 GET），不会修改路由器配置。
- 密码在日志与通知中脱敏；快照 JSON 仅存配置字段，不存 RouterOS 登录凭据。
- 试运行模式只读取并输出漂移结论，不落盘快照、不更新基线。

## 依赖

MoviePilot V3（>=3.0.0）。下拉框数据源来自宿主稳定接口 `app.sdk.services`
（`ServiceConfigHelper` / `DownloaderHelper` / `MediaServerHelper`），宿主不可用时自动降级为空选项，不影响备份主流程。
