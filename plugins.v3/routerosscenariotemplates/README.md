# RouterOS 场景模板一键部署（RouterOSScenarioTemplates）

把几套常见网络配置写成模板：勾选、看一遍每条要写什么、确认，然后一次性下发。写之前会留备份，
中途失败自动回滚。

开个远程观影端口、隔离访客或者开 IPv6，往往要跨好几个分区敲十几条命令，还得顾着顺序和兜底
drop。这里把这些成套写好，一次建好基线；日常的动态调度还是交给播放感知调度、带宽调度和 CF
优选 IP。

覆盖 IPv4/IPv6 防火墙、NAT、Mangle、地址列表、简单队列、IP/IPv6 地址、DHCPv6-PD、
WireGuard 接口与 Peer，共 10 个分区。

## 5 套内置模板

| 模板 | 动作数 | 涉及分区 | 风险 | 关键参数 |
|---|---|---|---|---|
| PT 友好 QoS | 3 | 地址列表 / simple queue / mangle | 中 | PT 主机、上下行上限 |
| 远程观影放行 | 2~3 | nat / filter | **高** | 媒体服务 IP+端口、外网端口、WAN 接口、可选 NAT 回环 |
| 访客网络隔离 | 4 | 地址列表 / filter | 中 | 访客网段、内网网段 |
| IPv6 基础开通 | 6 | DHCPv6-PD / IPv6 地址 / IPv6 防火墙 | **高** | WAN/LAN 接口、前缀长度 |
| WireGuard 回家 | 5~6 | WireGuard 接口 / IP 地址 / filter / 地址列表 / Peer | **高** | 端口、隧道网段、WAN 接口、可选客户端公钥 |

合计 21 条动作。标「高」的模板必须先在设置页勾选 **允许部署高危模板**，否则计划直接被拦截。

各套模板写了什么：

- **PT 友好 QoS**：地址列表登记下载机 → simple queue 限上下行 → mangle 打 `MP_A2_PT_UP`
  包标记并插到链首。与「带宽/Queue 智能调度」的队列可能叠加，已在风险文案里明示。
- **远程观影放行**：DNAT + forward 放行两条缺一不可；`lan_subnet` 填了才生成 Hairpin NAT。
  与后续 B1「外网访问向导」不同：这里是固定模板 + 手填参数，B1 会自动发现 MP 已连接服务。
- **访客网络隔离**：规则顺序即执行顺序（禁止访客→内网 在 放行 DNS 在 禁止访客→路由器 之前），
  全部插到同链首个兜底 drop 之前，避免变成死规则。
- **IPv6 基础开通**：先 DHCPv6-PD 拿前缀、LAN 口下发 RA，再补 ICMPv6 放行、已建连接回包、
  forward/input 两条兜底 drop。没有 IPv6 防火墙就开 IPv6 等于把内网设备裸奔公网。
- **WireGuard 回家**：接口 + 隧道地址 + UDP 握手放行 + 受信任地址列表 + forward 放行，
  公钥留空则跳过 Peer 步骤（只建接口）。

## 怎么用

1. **设置页**：目标路由器（可直接选「RouterOS 连接中心」里已保存的路由器）→ 勾选模板 → 填参数。
2. **详情页 → 生成/刷新预览**：逐条查看分区、中文含义、风险等级、状态（已存在/待写入）与等价
   RouterOS CLI 命令；此时会联网读取现状，已存在同标签的条目会标成「跳过」。
3. **详情页 → 确认一键部署**：备份 → 快照 → 逐条写入 → 报告。要撤销就点「回滚最近一次部署」。

首次建议先开 **试运行**，核对流程与命令后再真正部署。

## 写入和回滚

| 机制 | 行为 |
|---|---|
| 只新增 | 每个动作都带 `MP-A2[<模板>:<序号>]` 备注标签；**绝不修改或删除用户已有配置** |
| 幂等 | 同标签条目已存在则跳过，重复点部署不会堆积重复规则 |
| 插入位置 | 防火墙类动作按 `place-before` 插到兜底 drop 之前，mangle 标记插到链首 |
| 自动备份 | 部署前调用 `/system/backup/save` 在 RouterOS 本机留 `.backup`；失败默认**中止部署** |
| MP 快照 | 把涉及分区的现有配置导出成 JSON 存到插件数据目录 `snapshots/`（轮转保留 10 份），供人工对照 |
| 失败回滚 | 中途失败即停，按创建顺序**逆序 DELETE 本次新建条目**（只按记录到的 `.id`），不整表覆盖 |
| 手动回滚 | 详情页按钮复用同一回滚逻辑，只删最近一次成功部署创建的条目 |
| 参数校验 | IP/CIDR、端口范围、接口名字符集、带宽格式、WireGuard 公钥、控制字符清洗 |
| 分区白名单 | REST 路径只接受 `SECTIONS` 白名单，杜绝用户输入拼进 URL |
| 高危拦截 | 公网暴露 / IPv6 / WireGuard 三类模板需显式放行；必填缺失即阻断整份计划 |

> RouterOS 本机的 `.backup` 是最后一道保险，需要在 WinBox / CLI 里手动恢复；
> 「回滚」按钮只处理本次新建的条目，不是整机还原。

## 配置

- **连接**：地址、端口、HTTPS、账号、密码、超时、校验证书；`ros_connection` 下拉选中后自动覆盖
  手填字段。API 账号需要 `read / write / api / rest-api` 权限，创建系统备份还需 `policy`。
- **模板参数**：同名参数（如 `wan_if`、`lan_subnet`）在多模板间共用，填一次即可；前端未回传的
  字段回落到模板默认值。可选参数留空会跳过对应步骤。
- **管理标签前缀**：默认 `MP-A2`。改前缀会让旧条目不再被识别为「已存在」，请勿随意更改。
- **通知**：仅异常/失败（默认）、每次部署、关闭。
- **试运行**：不产生任何 PUT / POST 写请求，也不创建备份；计划保留，方便随后真正部署。

## 详情页 / API / 远程命令

- **详情页**：模板卡片、待确认计划表（中文含义 + 风险 + 等价命令）、最近部署报告、MP 快照清单、
  运行日志；7 个按钮全部绑定真实 API，破坏性操作带二次确认。所有动态文本做全角转义，
  避免 `[xxx]` 被前端当 Markdown 渲染成空药丸。
- **API**（前缀 `/plugin/RouterOSScenarioTemplates`）：
  `/preview` `/plan` `/apply` `/clear` `/rollback` `/backup` `/test` `/status` `/logs`。
- **远程命令**：`/a2_preview` `/a2_apply` `/a2_rollback` `/a2_status`。

## 已知限制

- 模板是**静态基线**，不做运行时状态机；播放/下载高峰的动态让路请配合现有调度插件。
- 回滚依赖 PUT 响应返回的 `.id`；某些 RouterOS 版本不返回 id 时，插件会重读分区按标签定位，
  若仍定位不到会在报告中明确列出「无法自动回滚」的条目。
- IPv6 与访客隔离的规则顺序按模板内顺序下发；若路由器已有更靠前的「全放行」规则，
  请到防火墙可视化管理器里把本模板规则上移。
- RouterOS v7 REST 路径与字段以 v7 为准；v6 不支持 REST，无法使用。
- 与 B1 若对同一端口重复部署，会产生两条 DNAT（标签不同），请先核对再执行。
