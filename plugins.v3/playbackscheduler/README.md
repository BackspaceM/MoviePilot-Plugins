# 播放感知调度（PlaybackScheduler）

读取 Emby / Jellyfin / Plex 的活动播放会话，按「是否转码 / 是否远程」自动判定播放状态，
对下载器（qBittorrent / Transmission）施加对应限速，并可选联动 RouterOS 简单队列；
支持在播文件保护标签、观影后自动删种、定时轮询与立即检查、MP 通知与 SSE 实时日志。

## 什么时候用

- NAS 上跑 Emby/Plex，同时用 qBittorrent/Transmission 做种；
- 家人开始看片时，自动把做种上传/下载限速，避免抢带宽导致卡顿/转码掉链；
- 远程转码（带宽最吃紧）时给最严格的限速，内网原画播放则基本不限速；
- 可选：在 RouterOS 上建一条简单队列，把播放时段的整体上行压住；
- 播放结束后按保留天数与做种率自动清理已看完的种子（仅 qBittorrent）。

## 状态与限速

插件把在播会话归为四种状态，并以此决定限速（Mbps，下载,上传）：

| 状态 | 含义 | 默认限速(下载,上传) |
| --- | --- | --- |
| idle | 无播放 | 0,0（不限制） |
| directplay | 内网原画 | 0,50 |
| transcode | 内网转码 | 0,30 |
| remote_transcode | 远程转码 | 0,15 |

- 下载器限速：qBittorrent 用字节/秒，Transmission 用 KB/秒，插件自动换算；
- RouterOS 队列上限可在「RouterOS 队列上限」留空（按上传限速推导，如 `50M/500M`）或手动指定；
- 限速可在「各状态限速」里按 `状态:下载,上传`（Mbps）自定义，留空则使用默认值。

## 配置项

- **媒体服务器**：每行一台，格式 `类型|名称|地址|密钥|路径映射|启用`
  - 类型：`emby` / `jellyfin` / `plex`
  - 路径映射：MP 容器路径 `::` 媒体服务器路径，多个用 `;` 分隔，`#` 开头为注释
- **下载器**：每行一台，格式 `类型|名称|地址|用户名|密码|启用`
  - 类型：`qbittorrent` / `transmission`
- **联动 RouterOS 队列**：填写地址/用户名/密码与队列上限（可选）
- **保护在播文件**：对在播种子打标签（默认 `playback-protect`），停止播放后自动移除
- **观影后自动删种**：空闲时按「保留天数 + 最小做种率」清理已看完的种子（仅 qBittorrent）
- **轮询周期(cron)**：默认 `*/5 * * * *`（每 5 分钟）
- **通知方式**：全部 / 仅异常 / 关闭，走 MoviePilot 全局通知
- **试运行**：只计算与记录，不实际改动下载器与 RouterOS

## 怎么用

1. 在 MP 插件市场添加本仓库后安装并启用；
2. 填入媒体服务器与下载器，按需调整限速与 RouterOS；
3. 保存后点「立即执行一次」验证；
4. 详情页可查看当前状态、在播会话、运行日志，并触发检查 / 恢复默认 / 清空历史；
5. 远程命令：`/playback_status`、`/playback_apply`、`/playback_reset`、`/playback_history_clear`。

> 关键步骤写入 INFO 级日志，MP「查看日志」经 SSE 实时推送。
