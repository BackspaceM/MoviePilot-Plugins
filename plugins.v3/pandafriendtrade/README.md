## 海报低价抢购（核心）

亭子里的**光影拍卖行**和个人**海报寄售场**原本是两个市场，v1.3.0 起合并为**一个项目、一个开关、一个监控循环**：

- 每轮同时读两个看板，把所有在售海报合成一个池子，**按到手价从低到高排序，先抢最便宜的**；
- 荷兰降价品按当前价直接买，竞价品按站点最低有效价 `minimum_bid` 出价（暗拍，不重复加价）；
- 默认只抢未拥有的；稀有度是中文多选下拉（普通/优秀/稀有/珍贵/传说），不选=不限；
- 价格超过 `单件价格上限`、余额不足、我已领先或已拥有的一律跳过；
- 不再有倒计时抢拍、加价档数、抢拍窗口等复杂策略——低价优先，看到便宜的就出手。

用法：
1. 配置页「③ 电影图鉴 · 海报」打开「开启海报低价抢购」，设 `单件价格上限`（0=不抢），按需选中文稀有度；
2. 详情页点「检查海报行情」看合并后的低价清单（只读不出价）；
3. 点「立即低价抢购」在试运行下看会抢哪些；确认后关掉试运行，点「启动/停止抢购」常驻监控。

站点暗拍说明：出价填的是「最终出价」，站点已把领先者 + 一档增量算进 `minimum_bid`，插件按此价出。
出价不可撤销，未中标本金全退、手续费（`bid_fee_bps`）不退。

**告警降噪**：网络偶发断连只记 DEBUG，连续失败 3 次才写 WARNING，恢复后计数清零；
请求头关闭 keep-alive、重试 3 轮且第 2 轮起换新 opener，避免站点单方面断连导致的 `RemoteDisconnected`。

## 领奖档位（中文多选，实时扫描）

配置页「领奖档位」是中文多选下拉，选项来自页面海报任务（`friendTradePosterTaskBoard`），按 `group` 带分类前缀：

- 【一次性典藏】：普通海报集合、优秀海报集合、稀有海报集合、珍贵海报集合、传说海报集合、完全图鉴
- 【主题片单交付】：动画电影之夜、悬疑犯罪现场、心灵成长之旅

**站点任务会更新**，所以选项不写死：详情页点「扫描任务档位」读取最新任务板并缓存，再回配置页下拉框即显示最新档位。
扫描失败时用内置兜底档位，下拉框不会空。留空=领所有 `status=claimable` 的档位。

## 安全设计

1. **默认试运行**：只产出计划写日志，不点任何按钮。
2. **不可逆动作默认全关**：买人/抢人/追回/释放必须自己打开，买人还要设价格上限与属性下限。
3. **保留名单**：填 UID 后这些佣人不参与工作、互动、保护、释放、派遣。
4. **不重复站点原生能力**：站点已开启自动派遣时，插件不派单、只结算。
5. **登录凭据隔离**：Cookie 只存本机插件配置，不写日志、不写仓库。
6. **渲染期零 IO**：配置页/详情页只读内存缓存，不联网、不读宿主 SDK；按钮端点全兜底。

## 代理

`proxy_url` 留空直连：HTTP `http://host:port`（可带账号）；SOCKS5 `socks5://host:port`
需容器安装 PySocks（`pip install PySocks`），否则记录提示并直连。「代理失败时降级直连」默认开。

## 升级兼容

旧的 `do_auction` / `do_consignment` / `auction_budget` / `consignment_budget` / `auction_rarities`
等细分字段仍保留在配置页底部的「高级兼容」区，老配置会自动映射到新项目
（总开关 = 旧拍卖或寄售开启，价格上限 = 两者较大值，稀有度 = 两者并集）。新用户只用上面的单一项目即可。

## 实现

全部走 `POST /ajax.php`，body `action=xxx&params[key]=val`，返回 `{ret, msg, data}`；
拍卖/寄售请求带 `X-Friend-Trade-Auction: 1` 头，寄售 `page_size=9`（站点合法值）。
纯标准库，无第三方依赖。规则在 `core.py`（可脱离宿主单测），HTTP 在 `site.py`，页面在 `renderer.py`。
每轮动作写进插件卡片「…」→ 查看日志，页面只留静态状态卡。
