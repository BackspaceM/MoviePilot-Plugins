# RouterOS 外网访问向导（RouterOSRemoteAccessWizard）

想在外面看片，得手工配 NAT、放行防火墙，还得记住哪个端口对应哪个服务。这个插件把
MoviePilot 里已经连好的媒体服务器、下载器 WebUI 和 MP 本体列出来，勾几个、确认一遍，
就一次性把映射写好，备注里还带上域名和「外网端口 → 内网服务」。

沿用 A2 场景模板的批量写入引擎：`roslink.py` 接连接中心，`clients.py` 只开放 nat / filter
两个 REST 分区，`engine.py` 负责预览比对、备份、批量下发和失败逆序回滚。

## 怎么用

1. 设置页选路由器（可以直接选连接中心里保存的），再勾选要放出去的服务。下拉里没有的
   服务，或者下拉读到的地址不对，就在「手动补充」按 `名称|内网地址|内网端口|外网端口|备注`
   写一行；同名会覆盖下拉项。外网端口留空会自动从起始端口往后找空位。
2. 详情页点「生成 / 刷新预览」：逐条看中文含义、风险和等价 RouterOS 命令。这一步会联网
   读现有规则，已存在同标签的条目标成「跳过」，已有 NAT 占用的外网端口也会自动避开。
3. 核对完点「确认一键部署」。想撤销点「回滚最近一次部署」。
4. 部署前后都可以点「连通性测试」：先测内网服务是不是活着，再用域名/公网地址 + 外网端口
   回连，验证 DNAT 和放行规则有没有生效。

第一次建议先开「试运行」，看一遍预览再真正写。

## 每个服务会写什么

| 分区 | 链 | 作用 |
|---|---|---|
| `/ip/firewall/nat` | dstnat | 把 WAN 口上的外网端口转到内网 IP:端口 |
| `/ip/firewall/filter` | forward | 放行转换后的流量，插到同链兜底 drop 之前 |
| `/ip/firewall/nat` | srcnat | 可选，填了内网网段才生成，插到链首，让内网设备用域名也能访问 |

协议默认 TCP，可改 UDP 或 TCP+UDP（后者不写 `protocol` 字段，等于全部）。每个条目都带
`MP-B1[<服务>:<用途>]` 备注标签；改标签前缀会让旧条目不再被认出来，别随便改。

## 写入和回滚

- 只新增带标签的条目，不修改也不删除用户已有规则；同标签已存在就跳过，重复点部署不会堆重复规则。
- 部署前在 RouterOS 执行 `/system/backup/save`，同时把两个分区的现状导成 JSON 存到 MP
  插件目录（轮转保留 10 份）。备份失败默认中止写入。
- 中途某条写失败就停下，按创建顺序逆序 DELETE 本次新建的条目。手动回滚走同一套逻辑。
- 公网映射默认拦住，必须勾「允许公网映射」；IP、端口、接口名、CIDR、域名、端口冲突都会校验。
- REST 分区白名单只含 nat 与 filter，用户填的东西不会拼进 URL。

RouterOS 本机的 `.backup` 是最后一道保险，要在 WinBox 或命令行里手动恢复；「回滚」按钮
只处理本次新建的规则，不是整机还原。

## 几件容易踩的事

- `to-addresses` 必须是 IP，媒体服务器地址写成域名的话，请在手动补充里换成实际 IP。
- 从 MP 容器访问自己的公网地址需要 Hairpin NAT，没配的话外网连通性测试会失败，用手机
  流量再试一次更准。
- 放行规则插到兜底 drop 之前，但如果链里更靠前还有「全放行」或更靠前的 drop，仍要到
  防火墙可视化管理器里核对位置。
- 同一个端口别在「场景模板一键部署」里再配一次，会生成两条 DNAT（标签不同）。
- 映射等于把服务放到公网，先确认有强密码或 HTTPS。RouterOS v6 不支持 REST，用不了。

## API 与命令

详情页按钮全部绑定真实 API：`/services` `/preview` `/plan` `/apply` `/clear` `/rollback`
`/probe` `/backup` `/test` `/status` `/logs`（前缀 `/plugin/RouterOSRemoteAccessWizard`）。

远程命令：`/b1_preview` `/b1_apply` `/b1_probe` `/b1_rollback` `/b1_status`。
