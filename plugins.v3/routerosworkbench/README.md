# RouterOS 统一工作台

把 4 个 ROS 插件的内容收进一个工具箱。地址、账号、密码填一次，也可以直接选连接中心里存好的那台；详情页用一排按钮切「概览 / 防火墙 / Queue / 备份 / 分流」，共用实时流量和拓扑卡片。

只读聚合，不改其它插件结构，也不往 RouterOS 写配置。客户端只发 GET，现状从 REST 读，插件的启用状态、版本和快捷入口从本地读。概览看系统资源和接口流量，防火墙看 filter / nat / mangle 并数一下放行和丢弃，Queue 看简单队列，备份看路由器上的 .backup / .rsc 和本地配置备份插件，分流看静态 DNS、地址列表和路由，带 MP-B3 / MP-A2 标签的条目会单独列出来。

快照存在插件数据里，点「一键刷新」重读一次；也能按 cron 定时刷新（默认每 10 分钟），某个分区读不到只记提醒，不中断其它页签。

限制：RouterOS 要 v7 并开 REST，API 账号至少有这些分区的读权限；速率是两次刷新之间 rx-byte / tx-byte 的差值，头一次只看到累计值；页签由服务端记住，点按钮走一次 API 才会切，不是前端本地切换。
