# RouterOS 防火墙可视化管理器

**这个插件的重点不是「一条条往里加规则」，而是让你看懂规则会做什么。**
已经知道规则效果的话，直接用 WinBox 导入更快。

## 典型用法
1. 设置页从「连接中心」下拉选一台已保存的路由器（也可手填），或直接在主界面点「测试连接」。
2. 两种批量导入任选其一：
   - 把 `.rsc` 导出、`/ip firewall filter print` 输出或 `chain=input action=...` 规则**粘贴到设置页文本框**；
   - 主界面点「上传 .rsc / 规则文件」选本地文件。
3. 保存后回主界面，每条规则都会翻成中文：**会做什么 / 影响谁 / 有什么风险 / 建议怎么做 / 等价命令**。
   常见场景会自动识别：WinBox(8291)/SSH(22)/Emby(8096) 等端口、端口转发、内网共享上网、
   FastTrack 与 Queue 冲突、动态黑名单、已建立连接放行、WAN 入口兜底阻断等。
4. 看懂并核对后再点「确认批量导入」：一次写入全部规则，默认插到兜底 drop 之前（不会变成死规则），
   改动前自动在 RouterOS 留备份；可先开「试运行」只看命令不落盘，或让导入的规则先禁用。

另外仍可表格化管理 `filter/nat/mangle/raw` 四表现有规则：按执行顺序展示、自动检测
影子规则 / 重复规则 / 缺失兜底，逐条启停 / 排序 / 删除；定时扫描隐患并推送通知。

**是管理器，不是自动对齐器——绝不批量删除用户真实规则，破坏性操作只作用于你明确点选的单条规则。**

详见插件包根目录 `README.md`。
