# 插件自动更新

设置页里「作者」和「插件」两个下拉都能多选。作者不勾就是所有作者，插件不勾就按选中的作者来；两个都勾了取交集。下拉清单来自本机插件表，打开设置页不会去等市场索引。

填 cron（默认 `0 5 * * *`，每天 5 点）就能定时跑，也可以回主界面点「立即运行」。只装市场里确实有新版的插件，默认跳过自己，免得更新到一半被重载打断。「试运行」只走流程不安装。

主界面就几个按钮和一行上次结果，逐条情况写在宿主日志里，也能通过 `/status`、`/history`、`/logs` 接口或 `/pau_status` 之类的远程命令查。

更新走 MoviePilot 自己的插件安装入口，不是直接改文件。宿主得允许调用安装接口，一般需要超级用户；市场索引读不到时只列本机版本、不会乱装；真去更新自己可能触发重载，这轮会断在半路。
