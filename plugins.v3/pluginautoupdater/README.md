# 插件自动更新

扫一遍本机装了哪些插件，列出 ID、名称、作者、当前版本、市场里的可更新版本和来源仓库。

设置页先选作者，再在另一个下拉里多选要更新的插件。选「全部作者」时下拉列出所有插件；插件下拉不选就更新这个作者下的全部插件。运行时会再筛一次，只动被选中、市场里确实有新版的那些，默认把自己跳过去，免得更新到一半被重载打断。

点「立即运行」马上跑一次，也可以填 cron（默认每天 5 点 `0 5 * * *`）让它定时跑。勾了「试运行」就只走流程、不真的安装，先看报告再决定。单次最多更新多少可以限，装失败会接着装下一个，结果逐条留在详情页的报告、更新记录和日志里。清记录只清这三样，扫描结果还在。

更新走的是 MoviePilot 自己的插件安装入口，不是直接改文件。

有几处得先心里有数：宿主得允许调用插件安装接口，一般需要超级用户权限；市场索引要能访问，读不到在线版本时只列本机版本、不会乱装；真去更新自己（勾了「允许更新自己」）可能触发重载，当前这轮会断在半路。
